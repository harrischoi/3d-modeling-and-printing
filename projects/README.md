# 프로젝트 목록

각 프로젝트는 별도 폴더로 관리합니다. 새 프로젝트를 추가할 때 `_project-template` 폴더를 복사해 사용합니다.

## BnW 활동

- [캠 거치대](cam-mount/): 각도별 브라켓과 곡선 홈을 적용한 조절식 캠 마운트
- [옆면 쓰레기 개폐 장치](side-waste-bin-mechanism/): 서보모터와 기어로 구동하는 회전식 내장 쓰레기통
- [모터 브라켓](motor-bracket/): 알루미늄 프로파일 프레임에 맞춰 제작한 3점 고정 모터 마운트
- [로봇팔 거치대](robot-arm-mount/): 로봇팔 하단부와 UWB 내장 공간을 결합한 상판 고정 구조
- [로봇팔 엔드 이펙터](robot-arm-end-effector/): 교체형 6면 와이핑 스틱과 후면 솔을 결합한 청소 도구

## 전공 프로젝트

- [건강 체크 박스](health-check-box/): 사용자 인증과 건강 상태 확인 기능을 통합한 데스크톱 장치

## 개인 프로젝트

- [탈부착식 창문 환기팬](removable-window-ventilation-fan/): 창문 장착 브라켓과 빗물막이를 결합한 환기 장치
