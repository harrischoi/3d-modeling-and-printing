# 3D 모델링 및 3D 프린팅

Fusion 360으로 설계하고 3D 프린팅으로 제작한 작업을 정리한 포트폴리오입니다.

## 프로젝트

프로젝트별 설계 의도, 모델링 과정, 출력 조건, 완성 사진과 관련 파일을 순차적으로 추가할 예정입니다.

| 프로젝트 | 설명 | 활동 |
| --- | --- | --- |
| [캠 거치대](projects/cam-mount/) | 설치 각도와 좌우 방향을 조절할 수 있는 캠 마운트 | BnW |
| [옆면 쓰레기 개폐 장치](projects/side-waste-bin-mechanism/) | 서보모터와 기어로 구동하는 회전식 내장 쓰레기통 | BnW |
| [모터 브라켓](projects/motor-bracket/) | 알루미늄 프로파일 프레임용 3점 고정 모터 마운트 | BnW |
| [로봇팔 거치대](projects/robot-arm-mount/) | 로봇팔 하단부와 UWB 내장 공간을 결합한 상판 고정 구조 | BnW |

## 저장 파일 안내

- `source/`: Fusion 360 원본 파일 (`.f3d`, `.f3z`)
- `exports/`: 공유 및 제작용 파일 (`.step`, `.stp`, `.stl`, `.3mf` 등)
- `images/`: 렌더링, 제작 과정 및 완성 사진
- `drawings/`: 도면과 관련 문서

## 사용 도구

- Autodesk Fusion 360
- 3D 프린터 및 슬라이서

> 각 프로젝트의 상세 사양과 출력 조건은 해당 프로젝트 문서에서 확인할 수 있습니다.
