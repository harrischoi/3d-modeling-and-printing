# 3D 모델링 및 3D 프린팅

Fusion 360으로 설계하고 3D 프린팅으로 제작한 작업을 정리한 포트폴리오입니다.

## 프로젝트

프로젝트별 설계 의도, 모델링 과정, 출력 조건, 완성 사진과 관련 파일을 순차적으로 추가할 예정입니다.

| 프로젝트 | 설명 | 파일 |
| --- | --- | --- |
| 준비 중 | 프로젝트 자료를 정리하고 있습니다. | — |

## 저장 파일 안내

- `source/`: Fusion 360 원본 파일 (`.f3d`, `.f3z`)
- `exports/`: 공유 및 제작용 파일 (`.step`, `.stp`, `.stl`, `.3mf` 등)
- `images/`: 렌더링, 제작 과정 및 완성 사진
- `drawings/`: 도면과 관련 문서

## 사용 도구

- Autodesk Fusion 360
- 3D 프린터 및 슬라이서

> 각 프로젝트의 상세 사양과 출력 조건은 해당 프로젝트 문서에서 확인할 수 있습니다.
